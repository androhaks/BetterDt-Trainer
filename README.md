# Devices Tycoon: BetterDt-Trainer ⚡

A feature-rich trainer mod for **Devices Tycoon**, built on top of the **BetterDT** framework. It allows you to flexibly manage in-game currency and research points through a sleek, customizable UI.

---

## 🚀 Key Features

* **Money Hack:** Quickly add **+$10,000,000** or **+$1,000,000,000** to your budget.
* **Research Points:** Instantly receive **+100,000 RP** for fast technology unlocks.
* **Custom UI:** A fully styled panel featuring backdrop glass-morphism and theme (color/paint) switching.
* **Interactive Toggles:** Hide or show specific sections directly inside the Settings window.
* **Screen Positioning:** Choose where the trainer panel resides on your screen (top-left, top-right, bottom-left, or bottom-right).
* **Keyboard Shortcuts:** Fast opening and closing using **F4** or **Insert**.

---

№How to install?
Download BetterDT.zip from the latest release (under "Assets"). Open the game folder: Steam → Library → right-click Devices Tycoon → Manage → Browse local files. A folder with Devices Tycoon.exe opens. Open the zip and copy everything in it into that folder: BetterDT_x64.ext.dll and the mods folder must end up right next to Devices Tycoon.exe, not in a new subfolder. Start the game. In Settings there is now a BetterDT section on the left – that means it works. Updates are automatic: when a new version is out, BetterDT downloads it when the game starts and tells you in the main menu. Click Restart now to use it right away, or Keep playing and it starts the next time you launch the game. You can turn automatic updates off in Settings → BetterDT.

Beta versions: turn on Beta versions in Settings → BetterDT to get test versions (GitHub pre-releases such as 0.4.1-beta.1) before the official release. They may have bugs. Once the official version is out, BetterDT moves on to it. When you turn betas off while you have one, Back to official installs the latest official version right away (it is also the line channel=beta in mods\betterdt.ini).

White screen? If the game screen ever turns white with a small sad face, BetterDT reloads the game by itself (you are back in the main menu; load your last save). The main menu then offers Report problem, which opens a prefilled bug report and copies it, so you can also paste it into the Steam discussion.

Uninstall: delete BetterDT_x64.ext.dll and the mods folder from the game folder. https://github.com/JelenXP/BetterDT/tree/main
